# NU Laguna Facility Action and Monitoring System (NUL-FAMS)

A web-based facility maintenance reporting system developed to streamline maintenance requests and monitoring.

## Live Demo

🔗 System URL: https://skye.page.gd/NUL_FAMS/

## Features

- User maintenance report submission
- Report tracking and status monitoring
- Admin dashboard
- Facility request management
- Proof image uploads

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Hosting:** InfinityFree
